Training weights initially give each campaign equal total mass, each polling firm equal campaign mass, each release equal firm mass and each party equal release mass. Reliability estimates each historical poll's total seat error using only strictly earlier campaigns, with ridge10 on metadata plus lead time. Fewer than two earlier elections gives neutral weights. Otherwise multiplier = .5 + .5 * clip(previous-weighted-mean-error / max(1,predicted-error), .5,2), bounded [.75,1.5]. Normalize within campaign afterward. That shrinkage/cap is a declared conservative assumption, not calibrated inverse variance. Every training release gets its own past-only estimate; its observed error cannot generate its own weight. Target outcomes are not read by feature/prediction/quality functions. Reliability changes training weights only; latest target group forecasts are averaged equally.
