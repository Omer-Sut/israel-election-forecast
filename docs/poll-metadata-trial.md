# E008: metadata for learning from individual polls

User clarification October23: poll quality should improve model training using who conducted a poll and its methodology, beyond days before the election. This is distinct from assigning final aggregation weights. The failed E005 expected-error predictor does not settle whether metadata improves main learners.

Protocol frozen before E008 scores: expanded audited six-election history, T-1 cutoff, same14day source gate, no bulk-index training. Three existing settings ridge10, forest depth3/leaf5/100trees, XGBoost depth2/50trees, seed20261021. Four ablations: existing aggregate features; individual poll-party rows with seats/zero/publication lead; added metadata; metadata plus conservative past-only reliability training weights. Poll-level basic control distinguishes changed training representation from metadata benefit. No broader family/parameter search.

Main residual label is actual final seats minus the individual poll projection. Features contain pollster aliases already audited by E005, publisher separately, log actual sample size and missing flag, reported fieldwork duration/publication lag and missing flags, and explicit reported mixed internet/telephone versus unknown mode. Original strings/source URLs remain exported. Training-only categorical vocabulary gives unseen firms an explicit unknown indicator. Creator-by-seat-size interactions allow size-dependent corrections; no historical party identity is equated across elections, no party-specific bias or geographic effect is claimed. Effective sample size/design effects, panel supplier, likely-voter screening, weighting and undecided treatment lack sufficient audited coverage and are deferred. AAPOR disclosure inventory: https://aapor.org/standards-and-ethics/disclosure-standards/ . Metadata being disclosed does not itself prove predictive usefulness.

Training weights initially give each campaign equal total mass, each polling firm equal campaign mass, each release equal firm mass and each party equal release mass. Reliability estimates each historical poll's total seat error using only strictly earlier campaigns, with ridge10 on metadata plus lead time. Fewer than two earlier elections gives neutral weights. Otherwise multiplier = .5 + .5 * clip(previous-weighted-mean-error / max(1,predicted-error), .5,2), bounded [.75,1.5]. Normalize within campaign afterward. That shrinkage/cap is a declared conservative assumption, not calibrated inverse variance. Every training release gets its own past-only estimate; its observed error cannot generate its own weight. Target outcomes are not read by feature/prediction/quality functions. Reliability changes training weights only; latest target group forecasts are averaged equally.

All predictions use earlier campaigns only. All eligible poll histories train poll learners; final latest-group releases supply target predictions. Compare fixed25% correction and diagnostic0/5/25/100%; correction chosen using at least two earlier OOF elections, total absolute integer error and smaller-fraction tie break. Exact rational mean used at0 to preserve frozen rounding ties. Final simplex/rounding enforces120. Preserve continuous scores and all per-party vectors. Families/ablations are not automatically selected. Repeated party/poll rows remain six campaigns; 2021/2022 were already inspected, not blind holdouts. Early missing fits are warm-up.

Run `python scripts/poll_metadata_trial.py`; hosted scientific workflow supplies existing locked dependencies. Standard-library baseline remains portable. Results, coverage, per-poll metadata/weights, training vocabularies, selections, hashes and plot are saved under output/poll-metadata-trial; compact public encoded logs allow durable recovery. Repeat compares numerical JSON/plot/summary, excluding runtime/commit manifest. Local source changes publish on a new topic branch stacked on PR18; no current forecast/turnout/merge/submission change. Execution/result evidence belongs in project-state and experiment-log after verification.
